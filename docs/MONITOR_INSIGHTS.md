# Monitor 与 Insights — build 48 本地测试

## 本次范围

沿用 build 47 的品牌、Planner、三种尺寸与原生玻璃面板；不重写渲染，不恢复 WidgetKit，不发布 Release。
App 新增 **Insights** 工作区：来源采集开关、逐窗口历史、近期节奏、条件耗尽区间、独立重置时间轴、规则回放和可关闭提醒。

## Phase 1：真实来源观测

- `CodexAppServer` 在有效 `account/rateLimits/read` 响应入口采样，不等待 Token 趋势请求。响应时间沿用到界面，避免趋势超时把接收时间推迟十秒。
- 每次新请求的成功响应，即使比例不变，也是一条新观测。同一请求重发不重复；玻璃设置、模型目录、系统时钟、缓存读取不生成观测。
- `ClaudeStatuslineStore` 在会话校验通过的桥接入口写入数据库，再替换兼容缓存。GUI 每两秒读取最新缓存不负责补历史，不漏掉两个 GUI 轮询之间正常接受的事件。
- SQLite 事务协调 App 与短时桥接进程，1.5 秒锁等待；进程中断可恢复。历史存储失败不破坏当前额度，但该次历史可能缺失，App 或桥接会显示有限错误，不回显输入。
- 开启 Codex 连续记录后，选择 Claude 展示也继续采集；App 仍只有一个 Codex 连接所有者。暂停记录时仍可手动查看当前 Codex，但不会继续写历史。Claude 仅有用户已启用桥接的被动输入，不启动或登录 Claude。
- Codex 账户查询使用独立请求 ID。账户变化会使旧请求失效，清除旧账户额度与目录；旧子进程的迟到输出/退出不得覆盖新连接。
- 修正旧解析器把单独 5h 窗口当成周额度的问题；只匹配确实提供的 300/10080 分钟窗口，缺失保持未知，严格拒绝无效数值和日期。

### 存储与隐私

`~/Library/Application Support/CodexQuota/observations.sqlite`

每条记录包含 schema/事件/观测 ID、来源、Provider、窗口、周期长度、使用比例、重置时间、实际收到时间、可选来源时间/共享池和可用性。Codex 账户仅保存邮箱哈希；Claude 会话仅保存指纹，不冒充账户标识。未知范围允许为空，不能用于安全的连续预测。

不保存邮箱原文、提示词、对话、项目内容、认证 token、完整设置或原始载荷。SQLite 未加密；私有目录 0700、数据库 0600，并拒绝符号链接和不安全文件。保持旧数据目录和兼容额度缓存，不导入旧 UI 快照来伪造过去观测。

原始记录保留 30 天，接受新事件及读取时清理过期记录；数据库上限 512 MiB。界面最多加载所选范围最新 20,000 条，达到上限会提示范围可能不完整；图形再作有界抽样，规则使用全部已加载原始记录。导出全部保留期记录为 JSON，128 MiB 上限到达时明确报错，不默默截断。清空只删除观测并重置提醒去重，不删除 Planner 反馈、账户、面板或玻璃设置。

## Phase 2：透明的节奏规则

- Codex/Claude × 5h/周额度独立分析，不相加、不换算 Token 或 API 费用。
- 只连续使用同一已知身份、来源、周期长度、共享池和重置点的观测；缺失、负跳变、重置、身份变化、Codex 超过 5 分钟或 Claude 超过 15 分钟缺测均分段，图表不跨缺口连线。
- Codex 超过 120 秒、Claude 超过 300 秒显示较旧，并停止预测。系统时钟继续走不代表数据更新。
- 最近一小时内至少 4 次连续观测、跨度至少 5 分钟、净消耗至少 3 个百分点，才估计近期速度。整数百分比分辨率不足时显示不可估计，不以零速度推断永久够用。
- 耗尽区间由最近净速度和端点 ±1 个百分点分辨率推导；不是统计置信区间。明确假设后续账户整体负载近似不变；跨重置或已经过去的预测不展示。其他设备和并发任务可能改变结果。
- 未核实服务是固定还是滚动恢复周期，不画假设性的“理想消耗线”。预计重置不代表届时必然获得固定容量。
- 回放仅用历史前缀预测约五分钟后的账户比例，与“保持上次读数”基线比较平均绝对误差；每窗口最多 12 个近期回放点，同时显示不可估计数。不是耗尽时间准确率，不宣称模型已经校准。
- 原生通知默认关闭，启用时才申请权限。新鲜读数从高于 20% 降至 20% 及以下时提醒；账户/周期隔离、去重、重启保留状态。预计重置仅在 App 运行、此前见到未来重置并刚越过时提醒；首次启用不补发旧提醒，长时间休眠不补发积压提醒。

## 文件与门禁

- `Shared/ObservationHistory.swift`：规范化观测、SQLite 与桥接共享文件边界。
- `Shared/UsageInsights.swift`：分段、速度、区间、回放和纯提醒决策。
- `App/InsightsStore.swift`：后台文件访问、读写错误、导出和原生通知；`App/InsightsView.swift`：现有原生工作区扩展。
- `Gate/ObservationHistoryProbe.swift`：重放、新鲜同值、缺失、暂停、保留期、导出、隐私、迁移/损坏、两进程并发、真实中断恢复与锁等待。
- `Gate/UsageInsightsProbe.swift`：冷启动、低分辨率、陈旧、重置/负跳变/缺口/身份变化、未来数据排除、回放与通知去重。
- `Gate/ModelCatalogProbe.swift`：生产连接上的真实响应入口、迟到/重复响应与账户/子进程隔离。

新增两个纯检查进入既有 `release-preflight.sh`；原有 Planner、三尺寸、单面板、非黑屏、同步、签名、双架构及最终 DMG 检查全部保留。完整运行只在隔离的 macOS 14/15/26 Xcode CI 用户；本机不运行假账户服务器或改变系统组件登记。

## 尚未宣称完成

没有真实 Claude 订阅验收；接入保持实验性。没有可验证的单任务额度归因、AI 训练、固定周期节奏线、耗尽时刻准确率验证或自动任务执行。历史从本版本启用后逐步积累，不能立刻得到过去 30 天的额度曲线。
Monitor 观测库与 Planner 人工反馈库分别存储，不能把账户期间变化直接用作任务成本。
