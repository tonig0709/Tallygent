# 大型面板图表 — 本地 build 51

这是基于 v0.7.0 / build 50 的本地功能测试，不修改已经创建的 v0.7.0 标签、安装包或 Release 草稿。

## 设置入口

在 App 的「玻璃设置」或桌面面板边缘设置弹窗中，找到「大型面板图表」：

- 图表内容：近 7 天 Token、过去 12 小时额度、过去 24 小时额度。
- 图形样式：柱状图或折线图，两类数据均可使用。

默认仍是现有七日 Token 柱状图。选择立即同步到 App 预览与已放置的同一个桌面面板，并在重启后保留。小型、中型面板以及玻璃参数和底层渲染不受影响。

## 数据含义

12h / 24h 与 Insights 一样展示 **剩余额度百分比**，5h 和周额度各占一个小图。它们不是小时 Token 数，也不是推算的消耗量。

- 折线使用真实观测点并保留连续区段，重置、身份切换、缺失与长间隔不连线；孤立观测显示为点。
- 柱状图取每个钟点小时内最后一次有效观测的剩余百分比。没有观测的小时留空，不补零、不推算。
- 历史从启用采集后开始，沿用既有有界读取上限；选择 24h 不等于已经拥有完整 24h 数据。
- 旧记录仍可作为历史显示，但会标注「旧记录 · 待更新」。当前身份未知，或历史不属于当前账户／绑定会话时，不展示其他身份的历史。

## 同步与隔离

仍由既有 InsightsStore 和单次 SQLite 读取提供数据，不新增账户连接或轮询。读取范围至少包含 24h，Insights 页选「近 1 小时」不会截断面板；清空历史会同步清空面板历史。

预览和桌面面板直接观察同一个历史 Store。图表时间域锚定最近一次历史读取时间，避免拖动玻璃滑杆时不断重建曲线；右上角系统时钟继续独立逐秒运行，不能被当作新数据。

柱线样式和内容分别保存在 `desktopPanelChartStyle`、`desktopPanelChartSource`；未知值安全回退到七日 Token 柱状图。修改图表设置不写入新的额度观测。

## 回归

`scripts/check-panel-trend.sh` 检查时间边界、账户／会话隔离、分段、采样、小时末次观测、DST、Insights 范围独立、读取失败和清除。它只使用临时数据。

完整门禁仍须在隔离 CI 用户执行，保留既有三尺寸、单面板、非黑屏、同步、内部布局、签名和 DMG 一致性检查。原生桌面的实际拖动、悬停及连续滑杆仍需人工确认，自动化不冒充真人操作。
